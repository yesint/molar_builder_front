      About MolAR builder

      MolAR builder is an independent clean-room implementation of a CHARMM-GUI-like system builder for MD simulations and molecular modeling. It uses no code or copyrighted assets from CHARMM-GUI. The implementation is based entirely on published research papers and open-source resources.

      Under the hood, the builder uses the molar molecular modeling library and the molar_vis visualizer. The frontend of the service is open source. The server backend is currently proprietary.

      Public beta

      MolAR builder is in public beta. To discourage automated submissions and cover server costs, each submitted system costs USD 0.50. This fee is your contribution as a volunteer beta tester. No particular result is guaranteed. No payment credentials are collected or stored by MolAR builder.

      By clicking “Submit”, you agree to use the builder and its output at your own risk. Both are provided without warranty of any kind, to the extent permitted by law.

      Generated systems are free to use for any purpose under CC BY 4.0. Data will be used to debug the builder and may also be used to train AI models.

      If you don’t agree with these terms, do not press “Submit”.
